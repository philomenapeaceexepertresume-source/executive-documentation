# Philomena Andreas Peace

A professional website for an Executive Documentation Specialist, featuring executive résumé writing, LinkedIn optimization, application documents, and a consultation enquiry form.

Built with React 19, TanStack Start, TypeScript, CSS, and Netlify Forms. The document artwork is rendered in CSS without stock photography or a fictional portrait.

## Local development

Use Node.js 22.13+ and pnpm. Run `pnpm install`, then `pnpm dev`. Netlify Forms processes submissions on Netlify deployments, rather than a standalone local Vite server.

Content and layout are in `src/components/MarketingPage.tsx`; metadata is in `src/data/site.ts`; styling is in `src/styles.css`. Consultation enquiries are available in Netlify Forms. No application credentials are required.
